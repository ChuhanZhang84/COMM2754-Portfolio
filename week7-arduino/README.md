# Week 7 – Arduino Creative Hacking

## Project: Love-o-Meter

This workshop introduced creative hacking through an Arduino temperature-sensing experiment. The aim was to use a temperature sensor to measure changes in temperature and control three LEDs in response.

## What We Did

We used an Arduino Uno, a breadboard, LEDs, resistors and connecting wires to build a circuit. We also used the Love-o-Meter example code provided in the Arduino Starter Kit without modifying it.

## Outcome

Our circuit did not work as intended, and we were unable to achieve the expected temperature-controlled LED response. This was part of our practical experience with connecting hardware components and testing a sensing system.
